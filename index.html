        Not set up
        Websites can't read Apple Health directly, so an iPhone Shortcut reads your steps from Health and sends them here. It runs on its own at the times you pick. Full steps are in the README ("Apple Health steps").
        The Shortcut needs these three values. Copy each one into the matching spot.
        • Web API key
        • Project ID
        • Steps key
          Private. Works like a password for your fitness data.
        If you ever think the steps key got out, change your password below. That turns off the old key; then copy the new one into the Shortcut.

        Goal calculator
